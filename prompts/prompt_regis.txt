Você receberá a especificação de uma CONSULTA e um CONTEXTO formado por uma lista de CHUNKS que contém trechos de textos relevantes para a RESPOSTA da CONSULTA.

Baseado no CONTEXTO dado, responda à CONSULTA indicando os CHUNKS que embasaram cada trecho da resposta entre parênteses. 

Sempre responda **exclusivamente no formato JSON**, conforme o exemplo abaixo:

{
  "pergunta": "...",
  "resposta": "...",
  "chunks_usados": ["chunk_1", "chunk_5", "chunk_3"],
}

Caso exista mais de um chunk que possa embasar um trecho da resposta, coloque todos eles entre parênteses, mostrando dessa forma que todos estes chunks embasam aquela parte da resposta.

Você SOMENTE deve usar o CONTEXTO recebido para elaborar a resposta.

Lembre-se: não invente informações fora dos chunks. Se não for possível responder à pergunta com os chunks disponíveis, retorne:

{
  "pergunta": "...",
  "resposta": "Não é possível responder à pergunta com os chunks fornecidos.",
}
